# account
Code following along the book Go: разработка приложений в микросервиснои архитектуре by Юлия Попова

Конфигурация сервиса Account

| Переменная окружения | Назначение                          | По умолчанию |
|----------------------|-------------------------------------|--------------|
| SERVICE_NAME         | Название сервиса                    | Account      |
| APP_ENV              | Окружение                           | local        |
| LOG_LEVEL            | Уровень логгирования                | in           |
| HTTP_PORT            | Порт, на котором поднято приложение | 9000         |
| HTTP_HOST            | Хост, но котором поднято приложение | localhost    |
